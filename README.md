# adobe-indesign-script-duplex-printing
Adobe Indesign Scipt for Duplex Printing

Steps
1. Prepare your data .csv
2. Make 2 docs for template front and back. Doc size is the paper you want to use for print. Mine is A4
3. In both template docs:
4. make your card design, unite all element in a group,
5. import and define your data merge,
6. create your merged document as multiple pages,
7. close others docs except the created merge docs,
8. run script rename group.
9. run script mirror
